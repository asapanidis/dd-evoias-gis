# Πιλοτικό Σύστημα Γεωχωρικών Δεδομένων
## Διεύθυνση Δασών Ευβοίας

Το παρόν αποθετήριο περιλαμβάνει την πιλοτική διαδικτυακή εφαρμογή προβολής και διαχείρισης γεωχωρικών δεδομένων της **Διεύθυνσης Δασών Ευβοίας**.

Η εφαρμογή αναπτύχθηκε στο πλαίσιο του έργου:

> **«Παροχή υποστηρικτικών υπηρεσιών για τη Δημιουργία γεωχωρικής βάσης δεδομένων της Δ/νσης Δασών Ευβοίας»**

Η υφιστάμενη εφαρμογή αποτελεί **proof of concept / πιλοτική υλοποίηση** και δεν αποτελεί τελική παραγωγική υποδομή της Υπηρεσίας.

## 1. Σκοπός

Σκοπός της πιλοτικής εφαρμογής είναι η αξιολόγηση μιας ενιαίας διαδικασίας για:

- προβολή γεωχωρικών δεδομένων,
- εισαγωγή νέων γεωχωρικών οντοτήτων,
- επεξεργασία γεωμετρίας και περιγραφικών στοιχείων,
- προσωρινή φόρτωση δεδομένων,
- οργάνωση δεδομένων ανά Δασαρχείο,
- διαμοιρασμό και δοκιμαστική αξιοποίηση μέσω web περιβάλλοντος.

Η εφαρμογή χρησιμοποιείται για δοκιμές και αξιολόγηση από τη Διεύθυνση Δασών Ευβοίας, ώστε να προσδιοριστούν οι ανάγκες πιθανής μελλοντικής παραγωγικής υλοποίησης.

## 2. Δασαρχεία

Η πιλοτική εφαρμογή υποστηρίζει:

- Δασαρχείο Ιστιαίας
- Δασαρχείο Λίμνης
- Δασαρχείο Χαλκίδας
- Δασαρχείο Αλιβερίου

Οι canonical τιμές του κοινού πεδίου `DASARXEIO` είναι:

- `Ιστιαίας`
- `Λίμνης`
- `Χαλκίδας`
- `Αλιβερίου`

## 3. Βασικές λειτουργίες

Η τρέχουσα πιλοτική εφαρμογή υποστηρίζει:

- εναλλαγή μεταξύ των 4 Δασαρχείων,
- προβολή Web Map ανά Δασαρχείο,
- Layer List,
- Attribute Table ανά θεματικό επίπεδο,
- επιλογή εγγραφής και zoom σε feature,
- μόνιμη εισαγωγή Shapefile / GeoJSON,
- προκαθορισμένα Shapefile templates,
- έλεγχο αντιστοίχισης πεδίων πριν από το upload,
- δημιουργία νέων features,
- επεξεργασία γεωμετρίας και attributes,
- διαγραφή features,
- προσωρινή φόρτωση GIS δεδομένων χωρίς αποθήκευση,
- προσωρινή σχεδίαση Point / Polyline / Polygon,
- προστασία system fields και `DASARXEIO` από μη επιθυμητή αλλαγή μέσω του front-end.

## 4. Τρέχουσα έκδοση

**Stable prototype: v7.2**

Η έκδοση **v7.2** έχει παγώσει προσωρινά για δοκιμαστική χρήση και αξιολόγηση από τη Διεύθυνση Δασών Ευβοίας.

## 5. Αρχιτεκτονική πιλοτικής υλοποίησης

```text
Κεντρική SDE / Enterprise Geodatabase
        ↓
Hosted Feature Layer
        ↓
4 Hosted Feature Layer Views
        ↓
4 Web Maps
        ↓
Custom Web Application
```

Το Hosted Feature Layer λειτουργεί ως κεντρική πηγή του πιλοτικού ArcGIS Online περιβάλλοντος. Κάθε Δασαρχείο εξυπηρετείται από ξεχωριστό Hosted Feature Layer View και ξεχωριστό Web Map.

## 9. Μελλοντική παραγωγική υλοποίηση

Σε περίπτωση θετικής αξιολόγησης, η λύση μπορεί να μεταφερθεί:

- σε ArcGIS Online / Portal του ΥΠΕΝ,
- σε άλλη εγκεκριμένη υποδομή της Υπηρεσίας,
- σε νέο ArcGIS Online περιβάλλον,
- ή σε υποδομή που θα προκύψει από νέα σύμβαση υποστήριξης / υλοποίησης.

## 10. Κατάσταση δεδομένων

Στην κεντρική SDE έχει ολοκληρωθεί βασική κανονικοποίηση του πεδίου `DASARXEIO`.

Στο τρέχον στάδιο **δεν έχει εφαρμοστεί στην SDE πλήρης χωρική επαναταξινόμηση όλων των features ανά Δασαρχείο** και **δεν έχουν γίνει splits γεωμετριών στα διοικητικά όρια**.

Αντίστοιχη χωρική επεξεργασία έχει δοκιμαστεί στο πιλοτικό Hosted Feature Layer και μπορεί να εφαρμοστεί μελλοντικά στην κεντρική βάση, εφόσον ζητηθεί από τη ΔΔΕ.

## 11. Περιορισμοί της πιλοτικής έκδοσης

Η παρούσα έκδοση:

- δεν διαθέτει ακόμη custom authentication,
- δεν αποτελεί production security architecture,
- δεν υλοποιεί πλήρη μηχανισμό συγχρονισμού SDE ↔ Hosted,
- δεν υποκαθιστά τις επίσημες διαδικασίες διαχείρισης και έγκρισης δεδομένων της Υπηρεσίας.

## 12. Κατάσταση έργου

Ολοκληρωμένα στο prototype:

- Attribute Table,
- QA / polishing pass,
- έλεγχος Hosted / Views / Web Maps,
- κανονικοποίηση `DASARXEIO` στην SDE για το συμφωνημένο scope,
- βασική τεκμηρίωση πιλοτικής αρχιτεκτονικής.

Σε αναμονή / επόμενη φάση:

- custom authentication,
- σχεδιασμός SDE ↔ Google Drive ↔ Hosted Layer,
- διαδικασία προσθήκης νέων Feature Classes,
- πλήρης production migration διαδικασία,
- πιθανή χωρική επαναταξινόμηση δεδομένων στην SDE.

## 13. Σημείωση

Η εφαρμογή βρίσκεται σε πιλοτική λειτουργία και τα δεδομένα, οι ρυθμίσεις και οι διαδικασίες μπορούν να τροποποιηθούν μετά από αξιολόγηση και οδηγίες της Διεύθυνσης Δασών Ευβοίας.
