Εργαλεία

Τα αντικείμενα αυτού του εργαλείου εμφανίζονται μόνο προσωρινά στον χάρτη. Δεν αποθηκεύονται σε Hosted Layer, View ή SDE και χάνονται με ανανέωση της σελίδας.
ZIP Shapefile, GeoJSON, DXF ή DWG. Τα CAD αρχεία θεωρούνται σε ΕΓΣΑ '87 / EPSG:2100. Η ανάγνωση DXF είναι ενεργή. Για πραγματικό DWG απαιτείται CAD converter και δεν γίνεται ψευδής μετατροπή σε DXF.
Όταν είναι ανοικτό αυτό το εργαλείο, χρησιμοποίησε τα εργαλεία σχεδίασης πάνω δεξιά στον χάρτη για σημείο, γραμμή ή πολύγωνο. Τα σχήματα μπορούν να μετακινηθούν ή να διορθωθούν προσωρινά.
Προσωρινά αντικείμενα: 0
Κατέβασε το επιλεγμένο θεματικό επίπεδο από τον ενεργό χάρτη. Στους χάρτες των Δασαρχείων λαμβάνονται μόνο τα features του αντίστοιχου View, ενώ στον χάρτη «Διεύθυνση Δασών Εύβοιας» λαμβάνονται τα συνολικά διαθέσιμα features.
Shapefile και DXF παράγονται σε ΕΓΣΑ '87. Το GeoJSON παράγεται σε WGS84.
Το DWG είναι πραγματικό CAD binary format και δεν δημιουργείται με απλή μετονομασία DXF. Η επιλογή θα ενεργοποιηθεί όταν συνδεθεί αξιόπιστος DWG converter.
Επεξεργασία στο Ιστιαίας
Οι αλλαγές εδώ είναι μόνιμες και γράφονται στο αντίστοιχο Hosted View / Source Hosted Feature Layer. Επιτρέπονται δημιουργία, αλλαγή γεωμετρίας, αλλαγή περιγραφικών πεδίων και διαγραφή. Το πεδίο DASARXEIO και τα system / lineage fields δεν εμφανίζονται για επεξεργασία, ώστε να προστατεύεται η αντιστοίχιση με το ενεργό Δασαρχείο.
Η εισαγωγή θα γίνει στο Ιστιαίας
Το DASARXEIO του αρχείου δεν χρησιμοποιείται. Η εφαρμογή επιβάλλει την τιμή του ενεργού Δασαρχείου.
Το πρότυπο είναι κενό Shapefile σε ΕΓΣΑ '87. Συμπλήρωσέ το σε ArcGIS Pro / QGIS και ανέβασέ το ως ZIP.
ZIP Shapefile: .shp + .shx + .dbf + .prj και, όπου υπάρχει, .cpg. GeoJSON: WGS84 / EPSG:4326.
